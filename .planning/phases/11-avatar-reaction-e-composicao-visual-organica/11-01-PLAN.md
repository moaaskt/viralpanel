## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File System Input → FFmpeg CLI | Caminho de arquivo da imagem de avatar ou áudio de locução não confiável pode quebrar o comando FFmpeg. |
| FFmpeg Math Filter (`geq`) → Memory/CPU | Equações matemáticas radiais operando em imagens de dimensões arbitrárias podem causar exaustão de CPU. |
| Storage File Path → Avatar Image Resolution | Caminhos relativos de assets de criadores podem ser alvos de Path Traversal. |

| T-11-02 | Denial of Service | `avatar.py::AudioReactiveAvatarAnimator` | medium | mitigate | Forçar `scale={size}:{size}` e `crop={size}:{size}` logo na entrada `[0:v]` antes de avaliar as equações do filtro `geq`, limitando estritamente a área de cálculo a 300x300 pixels com timeout de 90s. |
