  <files>src/viralpanel/studio/validator.py</files>
  <read_first>src/viralpanel/studio/renderer.py, src/viralpanel/branding.py</read_first>
  <action>Criar o módulo `src/viralpanel/studio/validator.py` contendo:
1. Dataclasses imutáveis tipadas `MediaStreamInfo` e `ValidationResult` (com status booleano `is_valid`, lista de `errors: list[str]`, `warnings: list[str]`, e `metrics: dict[str, Any]` contendo width, height, fps, video_codec, audio_codec, duration, pix_fmt).
2. Classe `MediaQualityValidator`:
   - Método `probe(file_path: Path | str) -> dict`: executa `ffprobe -v quiet -print_format json -show_format -show_streams` com timeout configurável (padrão 30s) e tratamento para arquivos corrompidos ou inexistentes.
   - Método `validate_rendered_video(video_path: Path | str, max_duration_diff_sec: float = 0.5) -> ValidationResult`:
     * Valida presença de exatamente 1 stream de vídeo e 1 stream de áudio.
     * Valida resolução exata `width == 1080` e `height == 1920` (aspect ratio 9:16).
     * Valida codec de vídeo `h264`, formato de pixel `yuv420p` e frame rate nominal `24 fps` (ou `24/1`).
     * Valida codec de áudio `aac` e sample rate `>= 44100`.
     * Valida duração: diferença absoluta entre duração de vídeo e duração de áudio `<= max_duration_diff_sec` para prevenir cortes prematuros.
   - Método `validate_avatar_asset(avatar_path: Path | str) -> ValidationResult`:
     * Valida que o asset intermediário de avatar preserva transparência com codec `png` e `pix_fmt == "rgba"`.
   - Método auxiliar `inspect_frame_pixels(video_path: Path | str, timestamp_sec: float = 1.0) -> dict`:
     * Extrai frame via FFmpeg para inspeção de pixels/amostragem se necessário (usado para auditar que o fundo composto não possui artefatos de caixa opaca).</action>
