# Plan 07-03: Biblioteca de Vídeos, Roteiros, Publicações e Integração E2E

## Objetivo
Completar o painel web com as visualizações do histórico de vídeos descobertos/selecionados, inspeção de roteiros originais gerados pelo Gemini, histórico de postagens nas redes sociais e validação do build de produção do frontend integrado com o backend.

## Tarefas Detalhadas

1. **Biblioteca de Conteúdo & Roteiros (`frontend/src/components/VideoLibrary.tsx`, `frontend/src/components/ScriptModal.tsx`)**:
   - Tabela e cards de vídeos descobertos (`SourceVideo`): título, autor, estatísticas de views/likes, viral score calculado.
   - Modal interativo para inspecionar o roteiro original gerado (`Script`): exibição clara do Gancho (Hook 0-3s), Desenvolvimento fluido (Body 4-45s) e Chamada para Ação (CTA).

2. **Histórico de Publicações (`frontend/src/components/PublicationHistory.tsx`)**:
   - Lista detalhada de publicações (`Publication`): plataforma (TikTok, Instagram Reels, YouTube Shorts), status (`published`, `pending_approval`, `scheduled`), data e link/ID externo.
   - Badges de identificação de rede social com cores profissionais (sem neon).

3. **Integração no Dashboard Principal (`frontend/src/App.tsx`)**:
   - Estrutura com abas ou seções bem delineadas:
     - Visão Geral (Monitor da esteira + Métricas)
     - Histórico de Execuções
     - Vídeos e Roteiros
     - Publicações
   - Gerenciamento de estado de carregamento e mensagens de erro amigáveis.

4. **Validação e Build do Frontend**:
   - Instalar dependências no diretório `frontend/` (`npm install`).
   - Executar `npm run build` para garantir TypeScript limpo e ausência de falhas no bundle Vite.
   - Testar suite de testes completa do backend (`.venv/bin/pytest`).
