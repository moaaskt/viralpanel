# Plan 07-02: Scaffold Frontend com React, Vite e Chakra UI (Design Sóbrio)

## Objetivo
Criar a base da aplicação frontend em `frontend/` utilizando Vite, React, TypeScript e Chakra UI v2. O design deve adotar uma estética corporativa limpa, profissional e elegante, sem cores neon ou saturação excessiva (atendendo estritamente a `DASH-03` e diretrizes de `AGENTS.md`).

## Tarefas Detalhadas

1. **Configuração de Pacotes (`frontend/package.json`, `frontend/vite.config.ts`)**:
   - Configurar dependências: `react`, `react-dom`, `@chakra-ui/react@^2.8.2`, `@emotion/react`, `@emotion/styled`, `framer-motion`, `lucide-react`, `axios`.
   - Configurar scripts: `dev`, `build`, `preview`.
   - Configurar proxy no Vite para encaminhar chamadas `/api` para `http://localhost:8000`.

2. **Definição de Tema Sóbrio (`frontend/src/theme.ts`)**:
   - Paleta de cores neutras e corporativas: Slate, Navy, Cool Gray, Blue profissional (`#1E293B`, `#0F172A`, `#2563EB`, `#F8FAFC`).
   - Bloquear e evitar explicitamente qualquer tom neon/fluorescente.
   - Configurar tipografia sóbria (Inter ou system fonts) e cards com sombras discretas e bordas refinadas.

3. **Cliente de Integração HTTP (`frontend/src/services/api.ts`)**:
   - Funções tipadas com `axios` ou `fetch` para consumir `/api/stats`, `/api/runs`, `/api/runs/trigger`, `/api/videos`, `/api/publications`.

4. **Componentes Principais**:
   - `Navbar.tsx`: Cabeçalho limpo com logo ViralPanel, badge de status do sistema e botão para atualizar dados.
   - `StatsCards.tsx`: Cards exibindo métricas consolidadas (vídeos minerados, roteiros gerados, publicações ativas, taxa de sucesso).
   - `PipelineMonitor.tsx`: Monitor da esteira diária Celery (`DASH-01`), indicando a fase atual, etapas concluídas em formato timeline/badge e botão para disparo manual da esteira com confirmação e feedback de loading.
