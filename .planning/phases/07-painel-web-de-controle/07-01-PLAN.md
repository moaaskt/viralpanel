# Plan 07-01: FastAPI REST API para Métricas, Esteira e Histórico

## Objetivo
Implementar a camada de API REST usando FastAPI para expor dados da esteira de automação, histórico de execuções, vídeos, roteiros, publicações e permitir o acionamento manual do pipeline Celery.

## Tarefas Detalhadas

1. **Atualizar `pyproject.toml`**:
   - Incluir `fastapi>=0.110.0`, `uvicorn>=0.28.0` e `httpx>=0.27.0` (em dev para testes do FastAPI TestClient).

2. **Criar Esquemas Pydantic (`src/viralpanel/api/schemas.py`)**:
   - `PipelineRunSchema`: id, run_date, status, current_stage, stages_completed, error_message, created_at, updated_at.
   - `SourceVideoSchema`: id, platform, external_id, title, author, views_count, likes_count, viral_score, status, created_at.
   - `ScriptSchema`: id, run_id, hook, body, call_to_action, estimated_duration_seconds, status, created_at.
   - `PublicationSchema`: id, run_id, platform, status, external_post_id, published_at.
   - `StatsResponse`: total_runs, total_videos, total_scripts, total_publications, publications_by_platform.
   - `TriggerResponse`: task_id, message.

3. **Criar Rotas REST (`src/viralpanel/api/routes.py`)**:
   - `GET /api/health`: Checagem rápida de saúde do sistema.
   - `GET /api/stats`: Agregação de estatísticas do banco de dados.
   - `GET /api/runs`: Lista execuções ordenadas pelas mais recentes.
   - `GET /api/runs/{run_id}`: Detalhe de uma execução específica.
   - `POST /api/runs/trigger`: Dispara `trigger_daily_pipeline.delay()` no Celery.
   - `GET /api/videos`: Lista vídeos fontes descobertos com paginação e filtros.
   - `GET /api/scripts`: Lista roteiros gerados.
   - `GET /api/publications`: Lista publicações e seus status.

4. **Configurar Aplicação FastAPI (`src/viralpanel/api/app.py`)**:
   - Inicializar `FastAPI(title="ViralPanel API")`.
   - Adicionar `CORSMiddleware` permitindo requisições de frontends locais.
   - Configurar montagem de diretório de arquivos estáticos (`/media`) para servir vídeos finais e áudios gerados pelo `StorageManager`.

5. **Testes Unitários da API (`tests/test_api.py`)**:
   - Testar `/api/health`.
   - Testar `/api/stats`.
   - Testar `/api/runs` e `/api/runs/{id}` com SQLite em memória.
   - Testar `/api/videos`, `/api/scripts`, `/api/publications`.
   - Testar `/api/runs/trigger` com mock de Celery task.
