| File System Paths → FFmpeg Command Arguments | Caminhos de arquivos de entrada (source, avatar, voz, legendas) interpolados na linha de comando e no filtro ASS. |
| FFmpeg Filter Complex Syntax → Process Execution | Strings de filtro complexo contendo expressões de overlay e filtros escalares. |
| Subprocess Execution → Host Resources (CPU/Memory) | Execução de codificação de vídeo de alta resolução (1080x1920) que pode causar exaustão de tempo ou recursos. |
